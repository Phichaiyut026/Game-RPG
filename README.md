# Game-RPG

**Ironvale** — เกม RPG 8 บิตแนวล่ามอนฟาร์มของในยุคกลาง เขียนด้วย HTML5 Canvas + JavaScript ล้วน ไม่ต้องติดตั้งอะไร

- 3 อาชีพ (Knight / Mage / Ranger) พร้อมสกิล อัปเลเวลสกิล และต้นไม้สกิล
- เควสเนื้อเรื่อง + ล่าค่าหัว, NPC, ร้านค้าและทั่งตีบวก
- ดันเจี้ยน 3 ชั้น, แมพเสริมแยกไฟล์ในโฟลเดอร์ `maps/`, บอสหลายตัว
- มินิแมพ, ตั้งค่าเสียง/ภาษา (ไทย/English)/ความยาก, เซฟอัตโนมัติ

## วิธีเล่น

เปิดผ่านเว็บเซิร์ฟเวอร์ local (เกมโหลดไฟล์ js/css แยก):

```bash
python .claude/serve.py 8123
```

แล้วเปิด <http://localhost:8123/rpg.html>

ปุ่มหลัก: ลูกศร/WASD เดิน · Space โจมตี · K/L สกิล · E คุย/เปิดหีบ · I กระเป๋า · T สกิล · N แผนที่ · Esc ตั้งค่า · H วิธีเล่น

## โครงสร้าง

| ที่อยู่ | หน้าที่ |
|---|---|
| `rpg.html` | หน้าเกม |
| `js/` | โค้ดเกม (กราฟิก เสียง ข้อมูล โลก การต่อสู้ UI ภาษา) |
| `maps/` | แมพเสริม หนึ่งไฟล์ต่อหนึ่งพื้นที่ (`registerMap({...})`) |
| `models/` | ภาพสไปรต์ตัวละคร/มอนสเตอร์ที่ export ออกมา |
| `css/` | สไตล์หน้าเว็บ |
