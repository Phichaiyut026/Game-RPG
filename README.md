# Game-RPG

**Ironvale** — เกม RPG 8 บิตแนวล่ามอนฟาร์มของในยุคกลาง เขียนด้วย HTML5 Canvas + JavaScript ล้วน ไม่ต้องติดตั้งอะไร

- 3 อาชีพ (Knight / Mage / Ranger) พร้อมสกิล อัปเลเวลสกิล และต้นไม้สกิล
- เควสเนื้อเรื่อง + ล่าค่าหัว, NPC, ร้านค้าและทั่งตีบวก
- ดันเจี้ยน 3 ชั้น, แมพเสริมแยกไฟล์ในโฟลเดอร์ `maps/`, บอสหลายตัว
- มินิแมพ, ตั้งค่าเสียง/ภาษา (ไทย/English)/ความยาก, เซฟอัตโนมัติ

## วิธีเปิดเล่น & บริหารเกม

เปิดผ่านเว็บเซิร์ฟเวอร์ local:

```bash
python .claude/serve.py 8123
```

- **ศูนย์บริหารและแดชบอร์ดเกม**: <http://localhost:8123/dashboard.html>
  - *สำหรับ Admin เท่านั้น* (ค่าเริ่มต้น: Username: `admin` / Password: `admin123`)
  - สามารถเปลี่ยนรหัสผ่านได้ในแท็บ "ตั้งค่า & ปรับสมดุล" ภายใน Dashboard
- **หน้าเกมหลัก (OPERATION: BIOHAZARD)**: <http://localhost:8123/rpg.html>
- **หน้าเกมย้อนยุค (Moonlit Run)**: <http://localhost:8123/moonlit_run.html>
- **หน้าคลังโมเดล (Model Gallery)**: <http://localhost:8123/models/index.html>

## โครงสร้าง

| ที่อยู่ | หน้าที่ |
|---|---|
| `dashboard.html` | แดชบอร์ดศูนย์กลางบริหารเกม จัดการเซฟ โกงสเตตัส สถิติ และเปิดเล่นเกม |
| `rpg.html` | หน้าเกมหลัก OPERATION: BIOHAZARD |
| `moonlit_run.html` | เกมวิ่งกระโดดคลาสสิก 8 บิต Moonlit Run |
| `js/` | โค้ดเกม (กราฟิก เสียง ข้อมูล โลก การต่อสู้ UI ภาษา) |
| `maps/` | แมพเสริม หนึ่งไฟล์ต่อหนึ่งพื้นที่ (`registerMap({...})`) |
| `models/` | ภาพสไปรต์ตัวละคร/มอนสเตอร์ที่ export ออกมา |
| `css/` | สไตล์หน้าเว็บ |
